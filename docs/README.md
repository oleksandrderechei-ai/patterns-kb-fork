# Docs map

Every page under `docs/` is one link from this map. Find the row for what you need, read the
clause that says when it helps, and open the page. A page no row reaches is a page nobody
finds, so the docs-map gate fails one, and it fails a row whose page has moved.

records rather than knowledge.
